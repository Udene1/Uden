# Compflow — State

Compflow is the cloud → control → evidence product for DORA/SOC 2/ISO.

Core concepts include evidence collection/freshness, infrastructure-to-control mapping, gaps, remediation proof, and truthful control status.

The first pilot target was delayed after the Azure subscription ended around 2026-09-19. The intended low-cost infrastructure direction is Oracle Ampere Always Free.

Commercial objective: reach a working state suitable for a paid pilot, then sell through evidence-driven investigation rather than assuming every lead is a Compflow lead.
